# Simon Game 🎮

A browser-based Simon Says memory game built with vanilla **HTML, CSS, and JavaScript**. Repeat the growing sequence of colored button flashes to level up — one wrong move and it's game over!

## 🕹️ How to Play

1. Press any key to start the game.
2. Watch and remember the sequence of colors that flash.
3. Click the buttons in the same order to repeat the sequence.
4. Each correct round adds one more color to the sequence.
5. Make a mistake and the game ends — your final score (level reached) is displayed.
6. Click **Restart** to play again.
